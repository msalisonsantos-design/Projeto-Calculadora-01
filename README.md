O script `calculadora.sh` foi desenvolvido para rodar em ambientes Linux / WSL. Para executá-lo corretamente:

1. Abra o seu terminal Linux ou WSL.
2. Certifique-se de que o arquivo possui permissão de execução rodando:
   ```bash
   chmod +x calculadora.sh
./calculadora.sh
